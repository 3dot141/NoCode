# MyJarvis-Brain Enhanced Skill

## 概述

MyJarvis-Brain Enhanced 是一个综合性个人知识管理和任务管理 Skill，基于 MyJarvis Obsidian 知识系统设计。

## 核心功能

### 模块 1：任务管理
- **四级层级管理**：年计划 → 月计划 → 周记 → 日记
- **任务状态跟踪**：Todo → In Progress → Done
- **任务分解**：将高层目标拆分为可执行任务
- **计划总结**：生成日/周/月总结
- **跨层级关联**：任务在不同层级间建立链接

### 模块 2：文档创建与知识沉淀
- **文档创建**：所有新文档首先在 Memory/Out/ 中创建（默认规则）
- **Memory 迁移**：将 Memory/Out/ 的笔记迁移到 Knowledge/2-Outputs/AI/（需用户明确指示）
- **批量捕获**：在总结时批量创建文档（仍遵循 Memory/Out 优先原则）
- **知识链接**：使用 Obsidian 双链建立知识关联

## 文档模板

### 任务管理模板
- **年度计划**：`Flow/01-Year/year.md`
- **月度计划**：`Flow/02-Month/YYMM-月度计划.md`
- **周记**：`Flow/03-Week/YYMM/YYMMDD-周记.md`
- **日记**：`Flow/04-Daily/YYMM/YYMMDD-日记.md`

### 知识文档模板
- **概念型**：理论知识、定义解释
- **操作型**：步骤指南、How-To
- **参考型**：API 文档、配置参考
- **回顾型**：项目复盘、经验总结

- 日记：`YYMMDD-日记.md`
- 周记：`YYMMDD-周记.md`

## 使用示例

### 创建周计划
```
用户：帮我创建下周的周记
→ AI 检查 Flow/02-Month/ 获取月度目标
→ 创建 Flow/03-Week/YYMM/YYMMDD-周记.md
→ 关联月度目标
→ 填充周计划模板
```

### 任务分解
```
用户：帮我分解"发布新产品"这个目标
→ 确定当前层级（如年度/月度）
→ 生成下一层级子任务
→ 在对应文档中添加分解后的任务
```

### 知识沉淀
```
用户：把这周的笔记整理到知识库
→ 扫描本周日记和周记的"知识沉淀候选"部分
→ 提取有价值的内容
→ **仅在用户明确说"沉淀到知识库"时**才迁移到 Knowledge/2-Outputs/AI/
→ 添加标签和链接
→ 在原文添加回链

### 创建普通文档（默认流程）
```
用户：分析这个需求并生成文档
→ 分析输入内容
→ 创建文档到 Memory/Out/YYMM/yymmdd-title.md
→ 添加标签和链接
→ **不自动迁移到 Knowledge**
```

## 与现有系统的关系

本 Skill 是现有 myjarvis-brain 的增强版：
- 保留现有功能（创建文档、添加任务、生成日记/周记）
- 新增系统化的四级任务层级管理
- 新增知识沉淀与任务管理的联动
- 向后兼容，现有工作流不受影响
